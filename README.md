# Ștefan Andrei Lucian — portfolio

A bilingual Bauhaus portfolio built as static HTML, CSS and JavaScript. English lives at `/`; Romanian at `/ro/`. Navigation, project descriptions, galleries and writing remain available without JavaScript. No backend or third-party embeds are required.

## Preview and build

Requires Node.js 20 or newer.

```sh
npm ci
npm run build
npm run dev
```

Open **http://localhost:3000**. The preview server serves `dist/`; run the build after edits. Upload the contents of `dist/` to a static host. The build currently generates 42 pages: the homepage, Projects archive, eight project details, Web Design archive and seven collections, Blog archive and two articles, each in both language routes.

The homepage retains four selected engineering/software projects. One Projects archive includes all eight software, robotics and mechanical projects. Web Design and Blog remain separate navigation destinations. Every project card opens its own page.

For GitHub Pages, follow the [deployment and update guide](docs/github-pages.md). The included Actions workflow builds and publishes `dist/` on pushes to `main`; original CAD source files and uncompressed videos are excluded from Git by `.gitignore`.

## Edit content

- `content/site.mjs`: personal information, homepage projects, skills, milestones, social URLs, shared translations and deployment origin.
- `content/catalog.mjs`: full project catalog, plain-language Romanian/English project descriptions, media mapping and design collections.
- `content/amnesia.mjs`: Amnesia’s bilingual description, feature sections, screenshot captions and GitHub link, shared by the homepage and detail pages.
- `content/sections.mjs`: translated labels for archives, galleries and model controls.
- `public/projects/`: original project descriptions, STEP assemblies, drawings and videos. Descriptions are editorially adapted into both languages in the catalog; editing a source description does not automatically translate it.
- `public/web_design/`: original design images, copied into public-facing assets when building.
- `public/posts/<date-slug>/index.md`: original articles with JSON-valued frontmatter. Related covers, charts and narration are copied when building. Article titles/summaries and surrounding navigation have Romanian translations in `scripts/pages.mjs`; the original English body and English narration are explicitly labeled on Romanian pages.
- `assets/styles.css` and `assets/pages.css`: design tokens, responsive homepage and detail-page styles.
- `scripts/home.mjs`, `scripts/layout.mjs`, `scripts/pages.mjs`: HTML templates and shared navigation/footer.

Run `npm run build` after changes. Generated HTML is written only into `dist/`; edit the content files and templates instead of generated HTML. Original project resources live together in `public/projects/`. The old root `projects/` and separate CAD page folders have been removed. Relative links support hosting below a subdirectory. Set the build environment variable `SITE_URL`, or the fallback in `profile.siteUrl`, to the full public base URL to generate canonical URLs, absolute sharing metadata, robots.txt and a sitemap. The GitHub Pages workflow supplies this URL automatically.

See the [project resource checklist](docs/project-resources.md) for what is supplied and what still needs portfolio media or context.

## CAD, video and galleries

Four supplied STEP assemblies are converted to GLB using OpenCascade through `occt-import-js`. These are the actual CAD meshes, with assembly colors preserved. A self-hosted model-viewer loads automatically when a project page opens; it supports orbit, zoom, reset and fullscreen where available. The **Wireframe** toggle switches between solid surfaces and triangle-edge geometry while preserving the camera position. Wireframe assets are generated by `scripts/wireframe.mjs` during the build and fetched when selected. A rendered preview remains visible while loading and without JavaScript.

Project pages provide no CAD download links. Original STEP files stay in `public/projects/` for local authoring, are excluded from `dist/`, and are blocked by the preview server. Old generated STEP download copies are removed during builds. Publish only `dist/`. Converted rendering assets necessarily remain retrievable by the browser; removing download controls is not access protection for displayed geometry.

Four supplied videos, including the Amnesia walkthrough, have browser-compatible H.264/AAC versions, poster frames and native playback controls. The local preview server supports byte ranges for seeking. Multiple screenshots, drawings or design images use a manual carousel with buttons, arrow keys and touch swipes. Clicking an image or its Fullscreen button opens an in-page fullscreen viewer with a close button, Escape support and keyboard gallery navigation. Closing returns focus to the current image’s button. Without JavaScript, all gallery images are displayed in order.

Prepared media is already included under `assets/media/projects/`, so normal builds do not require CAD conversion or FFmpeg. To refresh changed source files:

```sh
# Requires FFmpeg on PATH for video conversion; skips unchanged files.
npm run prepare:media

# Or process one type:
node scripts/prepare-media.mjs cad
node scripts/prepare-media.mjs video
node scripts/prepare-media.mjs images

# Build changed models before previewing or capturing posters.
npm run build
# With npm run dev active on port 3000 and Chrome installed:
npm run prepare:posters
npm run build
```

## Motion and identity

The hero uses an animated ASCII Möbius band; About uses a rotating ASCII icosahedron. Both have pause controls, pause offscreen and in background tabs, and respect reduced motion. The CV milestone loop becomes a static list when motion is reduced or JavaScript is unavailable.

The navigation portrait is an optimized edit of the supplied photograph; see [edit prompt and provenance](docs/portrait-edit.md). Résumé publication is disabled (`profile.resume: null`); the previous PDF is preserved locally under the ignored `.private/resumes/` folder. Neither attached ODT was copied into the website. Résumé filenames are ignored by Git, and the build excludes unpublished résumé PDFs and all ODTs. When the updated résumé is ready, explicitly add the approved PDF to assets, set `profile.resume` to its relative path and add a narrow `.gitignore` exception for that file. Social links include LinkedIn, Behance, Medium and GitHub. Project facts come from the CV, supplied descriptions and README; see [the GitHub and CV review](docs/project-review.md).

## Verification

```sh
npm run build
npm test
```

Browser checks use Playwright Core, installed Google Chrome and axe-core. They cover all generated pages and local destinations, responsive layouts, accessibility, keyboard/mobile navigation, language switching, galleries, automatic 3D loading and wireframe switching, exclusion of CAD source files, media playback and seeking, no-JavaScript fallbacks and reduced motion. For Edge, set `BROWSER_CHANNEL=msedge`.

Outfit is self-hosted under the SIL Open Font License (`assets/fonts/OFL.txt`). The self-hosted model-viewer license is in `assets/vendor/model-viewer-LICENSE.txt`.
